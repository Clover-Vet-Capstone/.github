# 🐾 Clover Vet Capstone Project-A26-CS123

> **AI-Powered Appointment Booking and Patient Data Management for Clover Vet Pamulang**

## 📌 About the Project

Clover Vet Capstone is a project focused on improving the appointment booking and patient registration process at Clover Vet Pamulang.

The project aims to develop an AI-powered chatbot and an admin dashboard to streamline booking data collection, assist customers with initial inquiries, and help clinic staff monitor appointment information more efficiently.

By combining Data Science, AI Engineering, and Full-Stack Development, this project brings together data-driven insights, AI-powered interactions, and application development into one integrated solution.

## 🎯 Project Objectives

- Streamline the appointment booking and patient registration process.
- Assist customers with appointment booking and questions about clinic services through an AI-powered chatbot.
- Improve the consistency of booking data collection.
- Provide a centralized dashboard for clinic staff to monitor booking information.
- Apply data analysis and AI model development to support the proposed solution.

## 🔄 Solution Overview

The proposed solution consists of three main components:

### 1. Intent Classification & Generative AI

Classifies customer messages into relevant intent categories and integrates Generative AI to support chatbot interactions, appointment booking, and questions about Clover Vet and its services.

### 2. Appointment Booking & Data Management

Collects relevant booking information, including pet owner details, pet information, selected treatment, and appointment preferences, to support a more structured booking process.

### 3. Admin Dashboard

Provides clinic staff with a centralized view of booking information to support appointment monitoring and administrative activities.
